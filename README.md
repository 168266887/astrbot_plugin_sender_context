# 对话者身份注入（astrbot_plugin_sender_context）

把**当前发言人的身份**写进 system prompt，让「按人分流」的人格设定有判断依据。

## 解决的问题

在人格里写这种条件——

> 面对 QQ 号 168266887 时用 A 人格，面对其他人用 B 人格

——通常不会生效。因为默认情况下模型收到的上下文只有消息文本，**没有发言人的 QQ 号**，
条件分支缺少判断依据，模型只能凭感觉挑一个（往往挑描述更具体的那个）。

本插件每次请求追加一段事实：

```
# 当前对话者（判断该用哪副人格时以此为准，不要凭感觉猜）
- 昵称=蓝色大肥鱼 | 账号=3196204560 | 场景=群聊(1109034668) | 平台=napcat
```

## 与「人格分流」插件的关系

| | 表现 |
|---|---|
| 只装本插件 | 模型**知道**对方是谁，能不能正确切换取决于模型的理解力（不够稳定） |
| 只装 人格分流 | 直接按 QQ 号硬切人格，不需要模型理解 |
| 两个都装 | 最稳：硬切人格 + 保留身份上下文（推荐） |

## 配置

| 项 | 说明 |
|---|---|
| `enabled` | 开关，默认开 |
| `include_group_id` | 是否附带群号，关掉则只标「私聊/群聊」 |

## 安装

放到 AstrBot 的 `data/plugins/` 下，重载插件即可。
